## Sobre o projeto

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido para apresentar minha experiência, formação acadêmica, principais tecnologias e projetos.

O projeto foi desenvolvido como uma aplicação web estática, com foco em:

- Design responsivo;
- Performance;
- Interface moderna;
- Experiência de navegação simples;
- Animações e microinterações;
- Identidade visual inspirada em ambientes de desenvolvimento e engenharia de software.

O site é publicado utilizando o **GitHub Pages**.
